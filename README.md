# 到点啦

一款有情绪价值的 Windows 打工人桌面工具。无需登录、无需联网，所有配置都保存在本机。

## 功能

- 下班倒计时：根据工作日、上下班时间实时计算，午休与下班状态自动切换。
- 工资进账：按月薪、每月计薪天数与有效工时估算今日收入，每秒跳动；支持一键隐藏金额。
- 假期倒计时：内置周末、元旦和发薪日，也可以添加旅行、生日、纪念日等自定义期待。
- 迷你置顶：切换为小窗，始终悬浮在桌面上。
- 老板键：点击“老板来了”或按 `Ctrl + Shift + B` 切换工作复盘界面，按 `Esc` 返回。
- 下班庆祝：到点自动彩带庆祝并发送系统通知，也可以随时手动下一场彩带雨。

> 工资数字只是按工时计算的估算值，不是真实银行到账信息，实际收入以工资单为准。

## 运行

需要 Node.js 22 或更高版本。

```powershell
npm install
npm start
```

## 验证与打包

```powershell
npm run check
npm test
npm run smoke
npm run build
```

打包后的便携版位于 `release` 目录，双击即可运行，无需安装。当前版本未配置商业代码签名，首次运行时 Windows 可能显示来源提示。

## 数据说明

设置和自定义期待使用 Electron 的本地存储保存，不会上传到网络。卸载或清理应用数据前，请先记录需要保留的内容。
