## 它是什么

“到点啦”是一个给打工人用的桌面小工具。它把上班时最常惦记的几件事，集中到一块安静的小仪表盘里：

- 还有多久下班；
- 今天已经“挣”到多少钱；
- 距离周末、假期和发薪日还有几天；
- 今天摸鱼了多久、喝水了没有；
- 老板突然出现时，如何一秒切换界面。

它不记录你的工作产出，不连接公司系统，也不要求账号。所有设置都保存在本机，打开就能用。

> 工资数字是按工时估算的“今天已经挣到多少”，不是银行到账信息，实际收入请以工资单为准。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| 下班倒计时 | 按工作日、上下班时间和午休时间计算；上班前、工作中、午休、下班后会自动切换文案与状态。 |
| 工资进账 | 按“月薪 ÷ 每月计薪天数 ÷ 8 小时”估算每秒收入，数字实时跳动；可一键隐藏金额。 |
| 期待日 | 内置周末、发薪日和元旦；也支持添加旅行、生日、纪念日、考试结束等自定义倒计时。 |
| 摸鱼计时 | 开始 / 结束今日摸鱼计时，累计时间会升级段位，并在本地按日期保存。 |
| 今日摸鱼签 | 随机生成“宜 / 忌 / 签级 / 说明”，可以反复摇签，给今天找一个摸鱼的理由。 |
| 带薪喝水 | 每天 8 杯水，点满触发彩带；把喝水这件小事也做成打卡。 |
| 老板键 | 点击“老板来了”或按 `Ctrl + Shift + B`，立即切换到工作复盘界面；按 `Esc` 返回。 |
| 下班庆祝 | 到点自动彩带庆祝并发送系统通知，也可以手动再下一场彩带雨。 |
| 隐私模式 | 一键隐藏工资金额，适合共享屏幕、录屏或旁边有人时使用。 |

## 三种使用方式

### 1. 放在副屏，当工作仪表盘

完整工作台适合放在副屏或大屏一角：左边下班，右边工资，下面是今天值得期待的日子。

### 2. 缩成小窗，始终置顶

小窗模式同时显示倒计时与工资，默认置顶。顶部“置顶中”按钮可以随时取消置顶，“恢复”按钮回到完整窗口。

### 3. 老板键，一秒切换

`Ctrl + Shift + B` 进入工作复盘界面，`Esc` 返回。它不隐藏进程，也不修改系统设置，只是把当前窗口切换成另一副面孔。

## 工资怎么算

应用按有效计薪工时估算，不包含午休：

```text
每日目标工资 = 月薪 ÷ 每月计薪天数
每秒收入   = 每日目标工资 ÷ 8 小时 ÷ 3600 秒
今日已挣   = 今日有效计薪秒数 × 每秒收入
```

默认参数：

- 月薪：`12000`
- 每月计薪天数：`21.75`
- 上班时间：`09:00`
- 下班时间：`18:00`
- 午休时间：`12:00—13:00`
- 工作日：周一至周五
- 发薪日：每月 10 日

这些参数都可以在设置里修改。

## 摸鱼段位

今日累计摸鱼时间越长，段位越高：

| 累计时间 | 段位 |
| --- | --- |
| 0 分钟 | 摸鱼见习生 |
| 10 分钟 | 摸鱼熟练工 |
| 30 分钟 | 摸鱼研究所所长 |
| 60 分钟 | 带薪休息大师 |
| 120 分钟 | 摸鱼传说 |

摸鱼计时、喝水记录、摸鱼签和设置都保存在本机，不上传网络。

## 快速开始

### 源码运行

需要 Node.js 22 或更高版本。

```powershell
npm install
npm start
```

### 构建 Windows 便携版

```powershell
npm run build
```

构建产物会生成在 `release` 目录。便携版双击即可运行，无需安装。

当前版本未配置商业代码签名，首次运行时 Windows 可能显示来源提示。

# JavaScript 语法检查
